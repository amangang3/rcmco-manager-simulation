# The Manager's Monday

A short, in-class simulation about managing people who work alongside an AI agent.

Everyone plays the same person: the nurse manager of a denial-appeals team at RCMco, a fictional revenue
cycle management company. An AI agent now drafts every appeal letter, and the nurses review, correct and
improve those drafts. The manager has one month of dashboard data on six nurses and two decisions to make,
with an optional third question if time allows.

**This is fiction.** RCMco and every person, number and event in it are invented for teaching.

## How it runs (about 25 to 30 minutes)

| Time | What happens |
|---|---|
| 2 min | Faculty reads the intro from the facilitator guide. |
| 1 min | The room forms groups of three, one laptop per group. |
| 10 min | Exercise 1, **Your dashboard**: make one call on each nurse (two Champions, two Coaches and two Flags). |
| 10 min | Exercise 2, **Your champions**: give each champion one role, with a one-sentence reason for each. |
| 5 min, optional | Part 3, **Next week**: write a short plan to keep the rest of the team motivated, then compare it with four approaches. |
| 5 to 10 min | The room reconvenes for the debrief. |

Each exercise ends with a reveal that shows the right calls and the framework behind them. Part 3 has no
right answer and no score. The facilitator
guide is linked quietly from every page.

## Run it

Open `index.html` in a browser. There is nothing to install and no network access is needed. It also runs
on GitHub Pages from the repository root.
